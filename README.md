# ashmitbohora.com

Personal portfolio of **Ashmit Bohora** — Statistics & Data Science @ UT Austin, Class of 2029.

The concept: *Full-stack. Literally.* A 3D burger built with Three.js disassembles as you scroll — each layer reveals a real shipped project. Underneath the show is a plain, fast, semantic-HTML site that works with JavaScript disabled.

## Stack

- [Astro 5](https://astro.build) — static-first, zero JS by default
- Plain CSS — fully custom-property driven, no framework
- [Three.js](https://threejs.org) — single vanilla island for the burger scrollytelling

## Develop

```bash
npm install
npm run dev      # local dev server
npm run build    # production build to dist/
npm run preview  # preview the production build
```

## Principles

- Recruiter path readable in ~30 seconds, with or without JS
- Every number on the site is measured and interview-defensible
- Semantic HTML + JSON-LD + llms.txt for human, search, and AI crawlers alike
